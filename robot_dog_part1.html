1큰 그림: 층으로 나눈 제어

로봇 개의 소프트웨어는 층층이 쌓여 있습니다. 위층일수록 느리고 큰 결정(어디로 갈까)을, 아래층일수록 빠르고 구체적인 결정(모터를 몇 도로)을 내립니다. 실제 Spot이나 Go2는 아래쪽 몇 층을 모델 예측 제어(MPC)나 강화학습 정책으로 바꾸기도 하지만, 층의 역할 분담은 같습니다.

이 페이지는 노란 띠가 붙은 세 층을 다룹니다. 위의 시뮬레이터에서 바닥을 탭하면 맨 위층부터 맨 아래층까지 전부 한 번씩 돕니다.

  1. ~1 Hz경로 계획목표까지 지나갈 점들1–2장 A*, RRT
  2. ~20 Hz경로 추종몸통 속도 명령 \((v_x, v_y, \omega)\)순수 추종(pure pursuit). 이때 쓰는 몸통 운동 모델은 이 페이지 6절
  3. ~50 Hz보행 스케줄러다리마다 언제 들고 언제 딛는지이 페이지 4절
  4. ~200 Hz발 궤적과 착지점발끝 목표 위치 \(\mathbf p\)이 페이지 5절
  5. ~500 Hz다리 역기구학관절 목표 각 \(q^*\)이 페이지 2–3절, 4–5장 로봇팔과 같은 원리
  6. ~1 kHz관절 제어모터 토크 \(\tau = k_p(q^*-q) - k_d\dot q\)10장 PID
옆에서 받쳐 주는 층: 상태 추정

IMU, 관절 엔코더, 카메라, 라이다를 합쳐 몸의 기울기·속도·위치와 주변 지도를 만듭니다. 모든 층이 이 값을 읽습니다. 7장 베이즈 필터가 여기서 쓰이고, 2부에서 다룹니다.

2다리 하나: 순기구학

다리 하나는 관절 3개짜리 작은 로봇팔입니다. Spot의 관절 이름을 빌리면 hx(엉덩이를 옆으로 벌리기), hy(엉덩이 앞뒤), kn(무릎)이고, 다리 4개를 합쳐 관절이 12개입니다. 관절 각 \(q=(q_1,q_2,q_3)\)를 알 때 발끝 위치를 구하는 일이 순기구학(FK)입니다.

먼저 다리가 놓인 평면 안에서 생각합니다. 허벅지 길이 \(L_2\), 종아리 길이 \(L_3\)이고, \(q_2=0\)이면 허벅지가 수직 아래를 향하며, \(q_2\)가 커질수록 뒤로 젖혀집니다. 무릎 \(q_3\)는 허벅지에 대한 상대 각입니다.

\[ x_A = -L_2\sin q_2 - L_3\sin(q_2+q_3), \qquad z_A = -L_2\cos q_2 - L_3\cos(q_2+q_3) \]

그다음 엉덩이 옆 관절이 이 평면 전체를 몸통의 앞뒤 축(\(x\)축) 둘레로 \(q_1\)만큼 돌립니다. 다리 평면은 몸통에서 옆으로 \(L_1\)만큼 떨어져 있는데, 왼쪽 다리는 \(s=+1\), 오른쪽 다리는 \(s=-1\)입니다.

\[ \mathbf p = R_x(q_1)\begin{bmatrix} x_A \\ sL_1 \\ z_A \end{bmatrix}, \qquad R_x(q_1) = \begin{bmatrix} 1 & 0 & 0 \\ 0 & \class{cosv}{\cos q_1} & -\class{sinv}{\sin q_1} \\ 0 & \class{sinv}{\sin q_1} & \class{cosv}{\cos q_1} \end{bmatrix} \]

이 페이지 로봇은 \(L_1=0.10\), \(L_2=0.32\), \(L_3=0.33\) m이고, 기본 서기 자세가 대략 \(q=(0,\,0.8,\,-1.6)\) rad입니다. 실제 Spot의 서기 자세도 이와 비슷합니다.

3다리 하나: 역기구학

걷기에서는 거꾸로 묻습니다. 발을 어디에 둘지 먼저 정하고, 그러려면 관절을 몇 도로 돌려야 하는지 구합니다. 4–5장 로봇팔에서는 반복 계산으로 풀었지만, 관절이 3개뿐인 다리는 삼각형 하나로 바로 풀립니다. 위 실습을 역기구학 모드로 바꾸고 발을 끌어 보세요.

① 옆 관절 \(q_1\): 앞에서 본 그림

발 위치 \((x,y,z)\) 중 \(y\), \(z\)만 보면 옆 관절이 길이 \(L_1\)의 막대를 돌리는 문제입니다. 다리 평면 안에서의 높이 \(z_A\)를 피타고라스로 구하고, 두 각의 차이로 \(q_1\)을 얻습니다.

\[ z_A = -\sqrt{\,y^2+z^2-L_1^2\,}, \qquad q_1 = \operatorname{atan2}(z,\,y) - \operatorname{atan2}(z_A,\,sL_1) \]

② 무릎 \(q_3\): 코사인 법칙

엉덩이에서 발까지 거리 \(r\)은 허벅지와 종아리가 만드는 삼각형의 세 번째 변입니다. 무릎이 뒤로 꺾이도록 음수 해를 고릅니다.

\[ r^2 = x^2 + z_A^2 = L_2^2 + L_3^2 + 2L_2L_3\cos q_3 \quad\Longrightarrow\quad q_3 = -\arccos\frac{r^2 - L_2^2 - L_3^2}{2L_2L_3} \]

③ 엉덩이 \(q_2\): 두 각의 차이

\[ q_2 = \operatorname{atan2}(-x,\,-z_A) - \operatorname{atan2}\!\big(L_3\sin q_3,\; L_2 + L_3\cos q_3\big) \]
\(r > L_2+L_3\)이면 arccos 안의 값이 1을 넘어 해가 없습니다. 발이 닿지 않는 곳이라는 뜻이고, 위 그림의 점선 원 밖입니다. 코드에서는 값을 \([-1,1]\)로 잘라 가장 가까운 자세로 멈춥니다. 무릎을 앞으로 꺾는 해(\(+\arccos\))도 있는데, 로봇마다 무릎 방향을 하나로 정해 둡니다.

4걸음새: 다리 네 개의 시간표

걸음새(gait)는 네 다리를 언제 들고 언제 딛는지 적은 시간표입니다. 모든 다리가 같은 주기 \(T\)로 움직인다고 보고, 0에서 1까지 도는 위상 \(\phi\)로 시간을 잽니다. 다리 \(i\)는 위상이 \(o_i\)에 이르면 발을 들어 스윙을 시작합니다.

\[ \phi(t) = \frac{t}{T} \bmod 1, \qquad u_i = (\phi - o_i) \bmod 1, \qquad \text{다리 } i = \begin{cases} \text{스윙(공중)}, & u_i < 1-\beta \\ \text{디딤(지면)}, & \text{그 밖} \end{cases} \]

\(\beta\)는 듀티비, 즉 한 주기 중 발이 땅에 붙어 있는 비율입니다. 표의 숫자만 바꾸면 전혀 다른 걸음이 됩니다.

넘어지지 않으려면: 지지 다각형

땅에 닿은 발들을 이은 볼록 다각형을 지지 다각형이라 합니다. 무게중심(CoM)을 바닥에 내린 점 \(\mathbf c\)가 이 안에 있으면, 그 자리에서 얼어붙어도 넘어지지 않습니다(정적 안정). 얼마나 여유가 있는지는 가장 가까운 변까지의 거리로 잽니다.

\[ m = \min_k \; d\big(\mathbf c,\ \text{변}_k\big) \qquad (\mathbf c\text{가 밖에 있으면 음수}) \]

트롯은 땅에 발이 둘뿐이라 다각형이 선분이 되고, 정적으로는 늘 넘어지는 중입니다. 넘어지기 전에 다음 발을 디뎌 받치는 동적 균형으로 걷습니다. 걷기도 몸을 가만히 두면 여유가 음수가 되는 순간이 있는데, 다리를 들기 전에 몸통을 나머지 세 발 쪽으로 옮겨 해결합니다. 아래에서 무게중심 옮기기를 켜고 끄며 비교해 보세요.

5발 궤적과 착지점

디딤 중인 발은 땅에 붙어 있으니, 몸이 속도 \(v\)로 나아가면 엉덩이에서 보기에 발은 \(-v\)로 뒤로 밀려납니다. 디딤 시간 \(T_{\text{st}} = \beta T\) 동안 밀려나는 거리가 보폭입니다. 스윙 중인 발은 같은 거리를 더 짧은 시간 \((1-\beta)T\) 안에 되돌아와야 하므로 몸보다 빨라야 합니다.

\[ L_{\text{step}} = v\,T_{\text{st}} = v\,\beta\,T, \qquad \bar v_{\text{swing}} = \frac{v}{1-\beta}\ \ (\text{지면 기준 평균}) \]

스윙 궤적은 수평으로는 부드럽게 출발해 부드럽게 멈추고, 수직으로는 높이 \(H\)까지 올랐다 내려오게 만듭니다. \(s\)는 스윙 진행률입니다.

\[ \mathbf p_{xy}(s) = \mathbf p_0 + (\mathbf p_1-\mathbf p_0)\,(3s^2-2s^3), \qquad z(s) = H\sin(\pi s), \qquad s\in[0,1] \]

엉덩이에 붙어서 본 발끝의 한 주기. 아래 직선이 디딤, 위 곡선이 스윙입니다. 다리 모양은 매 순간 3절의 역기구학으로 계산합니다.

어디에 디딜까: 레이버트의 발 디딤 규칙

스윙이 끝나는 순간 발을 어디에 내릴지가 균형을 좌우합니다. 1980년대 마크 레이버트(훗날 보스턴 다이내믹스 창업자)가 깡충 뛰는 외다리 로봇으로 찾은 규칙이 지금도 쓰입니다.

\[ \mathbf p_{\text{td}} = \underbrace{\mathbf p_{\text{hip}}}_{\text{착지 순간의 엉덩이}} + \underbrace{\frac{T_{\text{st}}}{2}\,\mathbf v}_{\text{대칭 보폭}} + \underbrace{k\,(\mathbf v - \mathbf v_{\text{cmd}})}_{\text{속도 보정}} \]

가운데 항은 디딤 구간의 한가운데에 엉덩이가 발 바로 위를 지나게 합니다. 마지막 항은 명령보다 빠르면 발을 더 앞에 디뎌 브레이크를 겁니다. 회전할 때는 다리마다 엉덩이 속도가 달라서, 몸통 중심에서 엉덩이까지의 벡터 \(\mathbf r_i\)를 써서 다리별 속도를 씁니다.

\[ \mathbf v_{\text{hip},i} = \mathbf v + \boldsymbol\omega \times \mathbf r_i \]

위 시뮬레이터는 마지막 항 없이 앞의 두 항과 이 회전 보정만 씁니다. 물리 엔진이 없어 속도가 명령과 늘 같기 때문입니다. MuJoCo에서 해 볼 과제로 남겨 두었습니다.

6몸통 운동 모델

계획 층에서 보면 12개 관절은 잊고 몸통 하나만 남깁니다. 3장의 2륜 로봇과 달리 로봇 개는 옆으로도 걸을 수 있어서(전방향, holonomic) 명령이 세 개입니다. 몸통 좌표계의 속도 \((v_x, v_y)\)를 방향각 \(\psi\)만큼 돌리면 세계 좌표계의 속도가 됩니다.

\[ \begin{bmatrix} \dot x \\ \dot y \end{bmatrix} = \begin{bmatrix} \class{cosv}{\cos\psi} & -\class{sinv}{\sin\psi} \\ \class{sinv}{\sin\psi} & \class{cosv}{\cos\psi} \end{bmatrix} \begin{bmatrix} v_x \\ v_y \end{bmatrix}, \qquad \dot\psi = \omega \]

\(v_y = 0\)으로 두면 3장의 유니사이클 모델과 똑같습니다. 실제 로봇은 속도 한계(Spot은 약 1.6 m/s)와 가속 한계가 있어서, 명령을 곧바로 따르지 않고 1차 필터로 부드럽게 따라갑니다. 위 시뮬레이터는 \(\tau = 0.3\) s를 씁니다.

\[ \mathbf v_{k+1} = \mathbf v_k + \alpha\,(\mathbf v_{\text{cmd}} - \mathbf v_k), \qquad \alpha = 1 - e^{-\Delta t/\tau} \]

4초 동안의 궤적. 실선이 로봇 개, 파란 점선은 같은 명령에서 \(v_y\)를 뺀 2륜 로봇입니다. 시간 슬라이더로 한 순간을 고르면 그때의 회전 행렬이 아래에 나옵니다.

7파이썬 실습: 걷는 함수 만들기

2–6절의 식을 그대로 옮긴 코드입니다. 위쪽 함수들은 완성본이고, 맨 아래 move()의 TODO를 학생이 채웁니다. MuJoCo Menagerie에 Unitree Go2와 Boston Dynamics Spot 모델이 있으니 둘 중 하나로 시작하면 됩니다.

import numpy as np

L1, L2, L3 = 0.10, 0.32, 0.33      # 옆 오프셋, 허벅지, 종아리 [m] (모델에 맞게 바꾸기)

def leg_fk(q, s):
    """관절각 q=(q1,q2,q3) → 엉덩이 좌표계의 발 위치. s=+1 왼쪽, -1 오른쪽 다리"""
    q1, q2, q3 = q
    xa = -L2*np.sin(q2) - L3*np.sin(q2 + q3)
    za = -L2*np.cos(q2) - L3*np.cos(q2 + q3)
    ya = s*L1
    c, sn = np.cos(q1), np.sin(q1)
    return np.array([xa, c*ya - sn*za, sn*ya + c*za])      # R_x(q1) @ [xa, ya, za]

def leg_ik(p, s):
    """발 위치 p → 관절각. 닿지 않으면 가장 가까운 자세"""
    x, y, z = p
    za = -np.sqrt(max(y*y + z*z - L1*L1, 1e-9))            # ① 다리 평면 안의 높이
    q1 = np.arctan2(z, y) - np.arctan2(za, s*L1)
    c3 = (x*x + za*za - L2*L2 - L3*L3) / (2*L2*L3)          # ② 코사인 법칙
    q3 = -np.arccos(np.clip(c3, -1.0, 1.0))                # 무릎은 뒤로
    q2 = np.arctan2(-x, -za) - np.arctan2(L3*np.sin(q3), L2 + L3*np.cos(q3))  # ③
    return np.array([q1, q2, q3])

# 다리 순서 (FL, FR, RL, RR) = (왼앞, 오른앞, 왼뒤, 오른뒤)
GAITS = {
    "walk":  dict(start=[0.25, 0.75, 0.00, 0.50], beta=0.75, T=1.00),
    "trot":  dict(start=[0.00, 0.50, 0.50, 0.00], beta=0.55, T=0.50),
    "pace":  dict(start=[0.00, 0.50, 0.00, 0.50], beta=0.55, T=0.50),
    "bound": dict(start=[0.00, 0.00, 0.50, 0.50], beta=0.50, T=0.42),
}

def leg_phase(phi, i, g):
    """전체 위상 phi에서 다리 i가 스윙인지, 그 구간의 진행률 s ∈ [0,1)"""
    sw = 1.0 - g["beta"]
    u = (phi - g["start"][i]) % 1.0
    return (True, u / sw) if u < sw else (False, (u - sw) / g["beta"])

def swing_point(p0, p1, s, H=0.09):
    b = 3*s**2 - 2*s**3                                     # 0에서 1로 부드럽게
    p = p0 + (p1 - p0) * b
    p[2] = p0[2] + H*np.sin(np.pi*s)
    return p

def raibert(p_hip, v_hip, T_st, t_left, k=0.0, v_cmd=None):
    """착지점 = 착지 순간 엉덩이 + 디딤 절반만큼 앞 (+ 속도 보정)"""
    p = p_hip + v_hip*(t_left + 0.5*T_st)
    if v_cmd is not None:
        p = p + k*(v_hip - v_cmd)
    return p
