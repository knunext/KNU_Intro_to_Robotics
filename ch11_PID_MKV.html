1추력기는 작은 로켓 엔진이다

네, 로켓처럼 가스를 내뿜습니다. 연료를 태워 생긴 뜨거운 가스(또는 탱크에 눌러 담은 질소 같은 압축 가스)를 좁은 노즐로 빠르게 뿜으면, 가스를 뒤로 밀어낸 만큼 비행체는 반대쪽으로 밀립니다. 뉴턴의 제3법칙, 작용과 반작용입니다.

\[ F = \dot m \, v_e \]

\(\dot m\)은 1초에 내뿜는 가스의 질량, \(v_e\)는 가스가 노즐을 떠나는 속도입니다. 가스를 많이, 빠르게 뿜을수록 힘이 큽니다.

재사용 로켓의 수직 이착륙 시험기, 달 착륙선, 요격체 호버링 시험 영상에서 보던 장면이 모두 이 원리입니다. 그런데 이런 추력기는 대부분 밸브를 열거나 닫는 것밖에 못 합니다. 드론 모터처럼 "힘을 37%만" 내는 게 안 됩니다. 이 제약을 어떻게 다루는지가 이번 실습의 핵심입니다.

2비행체를 숫자 세 개로 나타내기

화면 속 비행체는 평면(2D) 위에서 움직입니다. 위치를 알려면 숫자 세 개면 충분합니다. 수평 위치 \(x\), 높이 \(y\), 기울기 \(\theta\)입니다.

각 숫자가 어떻게 변하는지는 "힘 = 질량 × 가속도" 하나로 씁니다. 회전도 똑같이 "토크 = 관성 모멘트 × 각가속도"입니다. 점 두 개(\(\ddot x\))는 가속도를 뜻합니다.

\[ \begin{aligned} m\,\ddot x &= \class{hl-a}{F_s}\cos\theta - \class{hl-a}{T}\sin\theta + F_{\text{wind}} \\ m\,\ddot y &= \class{hl-a}{T}\cos\theta + \class{hl-a}{F_s}\sin\theta - m g \\ I\,\ddot\theta &= \class{hl-b}{\tau} \end{aligned} \]

복잡해 보이지만, 비행체가 거의 똑바로 서 있으면(\(\theta \approx 0\)) \(\cos\theta \approx 1\), \(\sin\theta \approx 0\)이 되어 식이 이렇게 단순해집니다.

\[ m\,\ddot x = F_s, \qquad m\,\ddot y = T - mg, \qquad I\,\ddot\theta = \tau \]
세 식이 서로 얽혀 있지 않습니다. 그래서 고도, 수평, 자세에 제어기를 하나씩 따로 붙일 수 있습니다. 자세 제어기가 \(\theta\)를 0 근처로 잡아 주는 동안에만 성립하는 약속이라, 자세 제어가 가장 빨라야 합니다.
항목값뜻
질량 \(m\)10 kg무게 \(mg\) = 98.1 N
주 추력기 \(T_{\max}\)150 N무게의 1.5배. 켜면 올라가고 끄면 떨어짐
측면 추력기 \(F_{s,\max}\)±25 N좌우 이동용
자세 추력기 \(\tau_{\max}\)±4 N·m회전용 (한 쌍이 반대로 밀어서 회전만 만듦)

3PD 제어와 중력 보상

목표 높이 \(r\)과 지금 높이 \(y\)의 차이를 오차 \(e = r - y\)라고 합시다. 원하는 가속도를 이렇게 정합니다.

\[ a_{\text{des}} = \class{hl-a}{K_p}\,(r - y) \;-\; \class{hl-b}{K_d}\,\dot y \]

\(K_p\) 항은 용수철입니다. 목표에서 멀수록 세게 당깁니다. \(K_d\) 항은 댐퍼(쇼크업소버)입니다. 빨리 움직일수록 반대로 브레이크를 겁니다. 용수철만 있으면 목표 주변을 계속 출렁이고, 댐퍼를 더하면 부드럽게 멈춥니다.

이제 이 가속도를 내려면 추력이 얼마나 필요한지 계산합니다. 여기서 중요한 한 줄이 있습니다.

\[ T_{\text{cmd}} = \frac{m\,(\class{hl-c}{g} + a_{\text{des}})}{\cos\theta} \]

\(\class{hl-c}{g}\)를 더하는 것이 중력 보상(피드포워드)입니다. 중력은 항상 아래로 당기니, 오차가 0일 때도 무게만큼(98.1 N)은 미리 밀어 줍니다. 이걸 빼면 비행체는 목표보다 조금 아래에서 "버티는" 자리를 찾아 멈춥니다. \(\cos\theta\)로 나누는 건 기울어지면 위로 가는 성분이 줄어드는 걸 채워 주기 위해서입니다.

게인을 고르는 요령도 있습니다. 이 식은 용수철-댐퍼 진동계와 같은 꼴이라서

\[ K_p = \omega_n^2, \qquad K_d = 2\,\zeta\,\omega_n \]

로 바꿔 생각할 수 있습니다. \(\omega_n\)은 반응 속도, \(\zeta\)는 출렁임 정도입니다. \(\zeta = 1\)이면 넘치지 않고 가장 빨리 멈춥니다. 기본값 \(K_p = 4,\ K_d = 4\)는 \(\omega_n = 2\), \(\zeta = 1\)입니다. 자세 축은 \(K_p = 25,\ K_d = 10\)으로 \(\omega_n = 5\), 고도 축보다 2.5배 빠릅니다.

그럼 PID의 I는? 적분항은 "정체를 모르는 일정한 힘"을 지워 줍니다. 중력은 크기를 알기 때문에 미리 더했지만, 화물을 실어 실제 질량이 달라지면 계산한 중력 보상이 틀립니다. 실험 ⑥에서 오차가 남는 걸 확인하고 \(K_i\)를 올려 보세요. \[ a_{\text{des}} = K_p\,e - K_d\,\dot y + \class{hl-a}{K_i \textstyle\int e\,dt} \]

4켜고 끄기만 되는 추력기 다루기

PD 제어기는 "113 N 주세요"처럼 연속적인 값을 내놓는데, 추력기는 0 N 아니면 150 N입니다. 두 가지 방법을 비교해 봅니다.

On-Off (뱅뱅 제어). 필요한 힘이 있으면 한 주기(20 ms) 동안 꽉 켜고, 아니면 끕니다. 가장 단순하지만 목표 근처에서 켜짐과 꺼짐을 끝없이 반복합니다(채터링). 작은 오차에는 반응하지 않도록 데드밴드를 두면 덜 깜빡이지만 그만큼 정밀도가 떨어집니다.

PWM (펄스 폭 변조). 한 주기 안에서 켜 두는 시간의 비율로 평균 힘을 맞춥니다.

\[ t_{\text{on}} = \frac{|F_{\text{cmd}}|}{F_{\max}}\,\Delta t \]
\[ \bar F = \frac{t_{\text{on}}}{\Delta t}\,F_{\max} = |F_{\text{cmd}}| \]

떠 있으려면 98.1 N이 필요하니 \(98.1 / 150 \approx 65\%\), 즉 20 ms마다 13 ms씩 켜면 됩니다.

현실의 밸브는 너무 짧게는 못 엽니다. 이 한계를 최소 점화 시간이라 하고, 그보다 짧은 펄스는 아예 쏘지 않습니다. 결국 세 가지가 서로 당깁니다. 정밀도를 올리면 밸브가 더 자주 열리고(수명), 데드밴드를 넓히면 연료와 밸브는 아끼지만 오차가 커집니다. 화면 아래 숫자 "밸브 열림 / 초"와 "평균 사용 추력"으로 이 저울질을 직접 재 볼 수 있습니다.

5센서와 칼만 필터

지금까지는 제어기가 위치와 속도를 정확히 안다고 가정했습니다(실험 ①~③의 "참값"). 실제로는 센서로 재야 하고, 센서는 늘 조금씩 틀립니다.

센서속도재는 것성질
IMU 가속도계50 Hz가속도 (20 ms 평균)빠르지만 잡음. 적분하면 오차가 쌓임
IMU 자이로50 Hz회전 속도 \(\dot\theta\)빠르지만 잡음
위치·자세 센서10 Hz\(x, y, \theta\)느리고 잡음 있지만 오차가 쌓이지 않음

위치를 그냥 미분해서 속도를 구하면? 위치 잡음 \(\sigma_p = 5\) cm, 측정 간격 0.1 s일 때 속도 잡음은

\[ \sigma_v \approx \frac{\sqrt 2\,\sigma_p}{\Delta t} = \frac{\sqrt2 \times 0.05}{0.1} \approx 0.7\ \text{m/s} \]

로 커집니다. \(K_d\)가 이 잡음을 그대로 증폭해서 추력기가 쓸데없이 깜빡입니다. 실험 ④에서 확인하세요.

칼만 필터는 두 센서의 장점을 섞습니다. 상태를 \(\hat{\mathbf x} = [\,\hat p,\ \hat v\,]^\top\)(추정 위치, 추정 속도)로 두고 두 단계를 반복합니다.

예측 (50 Hz). IMU 가속도로 위치와 속도를 한 걸음 굴립니다. 동시에 불확실성 \(P\)는 조금씩 커집니다.

\[ \hat{\mathbf x}^- = \underbrace{\begin{bmatrix}1 & \Delta t\\ 0 & 1\end{bmatrix}}_{F}\hat{\mathbf x} + \underbrace{\begin{bmatrix}\Delta t^2/2\\ \Delta t\end{bmatrix}}_{B} a_{\text{IMU}} \]
\[ P^- = F P F^\top + \class{hl-b}{Q} \]

보정 (10 Hz). 위치 센서 값 \(z\)가 오면 예측과 비교해서 고칩니다. 위치만 재므로 \(H = [\,1\ \ 0\,]\)이고, 이때 칼만 이득은 이렇게 단순해집니다.

\[ K = \frac{1}{\class{hl-a}{P^-_{11}} + \class{hl-c}{R}} \begin{bmatrix} \class{hl-a}{P^-_{11}} \\ P^-_{21} \end{bmatrix} \]
\[ \hat{\mathbf x} = \hat{\mathbf x}^- + K\,(\class{hl-c}{z} - \hat p^-), \qquad P = (I - K H)\,P^- \]

\(K\)의 첫 칸은 0과 1 사이 숫자입니다. 예측이 불확실하면(\(\class{hl-a}{P^-_{11}}\)이 크면) 1에 가까워져 측정을 믿고, 센서 잡음 \(\class{hl-c}{R}\)이 크면 0에 가까워져 예측을 믿습니다. 둘째 칸은 "위치가 틀렸다면 속도도 이만큼 틀렸겠지" 하고 속도까지 고쳐 줍니다. 미분 없이 속도를 얻는 비결이 여기 있습니다.

\(\class{hl-b}{Q}\)는 "내 예측 모델을 얼마나 못 믿는가"입니다. 실험실의 Q 배율을 0.01로 내리면 필터가 센서를 무시하다 늦게 따라가고, 100으로 올리면 센서 잡음을 그대로 따라갑니다. 위쪽 "칼만 필터 들여다보기"에서 \(P\)와 \(K\) 칸이 어떻게 바뀌는지 보세요.

자세 축도 같은 구조입니다. 상태는 \([\,\theta,\ \dot\theta\,]\), 예측에는 내가 쏜 자세 추력기 토크를 쓰고, 보정은 자이로(\(\dot\theta\), 50 Hz)와 자세 센서(\(\theta\), 10 Hz) 두 가지로 합니다.

6코드로 옮기면

시뮬레이터 안의 핵심 로직을 Python으로 옮긴 것입니다. 고도 축 하나만 보입니다. 수평 축은 중력 보상만 빼면 같고, 자세 축은 상태만 \([\theta, \dot\theta]\)로 바뀝니다.

import numpy as np

G, M = 9.81, 10.0          # 중력, 제어기가 알고 있는 질량
DT = 0.02                  # 제어 주기 (50 Hz)
T_MAX = 150.0              # 주 추력기 최대 추력

def altitude_pd(r, y, vy, theta=0.0, kp=4.0, kd=4.0):
    a_des = kp * (r - y) - kd * vy                          # 용수철 + 댐퍼
    return M * (G + a_des) / max(np.cos(theta), 0.5)      # 중력 보상

def pwm(cmd, f_max, deadband=0.0, t_min=0.004):
    duty = min(abs(cmd) / f_max, 1.0)
    if duty < deadband:
        return 0.0
    t_on = duty * DT
    return np.sign(cmd) * (t_on if t_on >= t_min else 0.0)   # 켜 둘 시간 [s]

class KalmanAxis:
    """상태 x = [위치, 속도]"""
    def __init__(self, p0, sigma_a, sigma_z):
        self.x = np.array([p0, 0.0])
        self.P = np.eye(2) * 0.01
        self.F = np.array([[1.0, DT], [0.0, 1.0]])
        self.B = np.array([DT**2 / 2, DT])
        self.H = np.array([[1.0, 0.0]])
        self.Q = sigma_a**2 * np.outer(self.B, self.B)
        self.R = np.array([[sigma_z**2]])

    def predict(self, a_imu):
        self.x = self.F @ self.x + self.B * a_imu
        self.P = self.F @ self.P @ self.F.T + self.Q

    def update(self, z):
        S = self.H @ self.P @ self.H.T + self.R
        K = self.P @ self.H.T @ np.linalg.inv(S)
        self.x = self.x + (K @ (np.atleast_1d(z) - self.H @ self.x)).ravel()
        self.P = (np.eye(2) - K @ self.H) @ self.P

# 제어 루프
kf = KalmanAxis(p0=0.5, sigma_a=0.35, sigma_z=0.05)
for k in range(steps):
    kf.predict(imu.vertical_accel())        # 50 Hz
    if k % 5 == 0:
        kf.update(pos_sensor.read_y())      # 10 Hz
    y, vy = kf.x
    t_on = pwm(altitude_pd(3.0, y, vy), T_MAX)
    vehicle.fire_main(t_on)
